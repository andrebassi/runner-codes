## Story

As a serviço, I want um pool por linguagem e um serviço de execução, so that cada job pegue uma VM pronta e a destrua no fim.

## Acceptance Criteria

1. `domain.ValidateJob`: linguagem conhecida, stdin ≤ 1 MB, nome de arquivo sem `/` nem `..`, timeout entre 1 e 300 s (padrão 10).
2. `PoolManager`: N VMs prontas por linguagem; `Take` entrega cada VM uma vez; reposição assíncrona com no máximo 2 boots simultâneos por linguagem.
3. Pool vazio → boot síncrono. Timeout → `Kill` e `Result{TimedOut:true, Status:"failed", Error:"E003: timeout"}`.
4. A VM é destruída depois de todo job, inclusive em erro (`defer`).
5. `Close()` mata todas as VMs do pool.
