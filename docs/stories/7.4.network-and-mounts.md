## Story

As a pessoa ou agente que roda código não confiável numa máquina, I want ligar rede de saída com uma política (nomes,
CIDRs, faixas privadas), publicar portas e montar diretórios do host, so that a máquina instale pacotes, chame APIs
e sirva um app — com o mínimo aberto e cada recusa registrada.

## Acceptance Criteria

1. Máquina nasce sem placa de rede. `--net`/`net = true` liga a saída através de um gateway em userspace no
   processo da VM; qualquer regra de saída implica rede.
2. Política:
   - `allow_hosts` (apex + subdomínios, `=exato`, `*.sub`), `allow_host_patterns`, `allow_cidrs`, `deny_cidrs`,
     `block_private`/`allow_private`;
   - qualquer allow inverte o padrão para negar;
   - nome negado recebe NXDOMAIN; conexão negada recebe RST; os dois sem timeout;
   - IP só passa se for estático ou aprendido do DNS de um nome permitido.
3. Piso que nenhuma regra abre: metadata de nuvem e link-local. O loopback do host só abre com `allow_cidrs`
   explícito, nunca por IP aprendido em DNS.
4. Recusas registradas em `egress-denials.log` no diretório da máquina.
5. `machine update` (CLI) e `PUT /machines/:name/egress` (API) trocam a política com a máquina ligada; vale na
   próxima conexão; IPs de nome removido são esquecidos.
6. Portas: `-p`/`ports`, TCP e `/udp`, só em 127.0.0.1, até 64. Porta sem `--net` não abre saída.
7. Volumes `-v`/`volumes` `HOST:GUEST[:ro]` por virtiofs, montados a cada start antes do workdir e do init. O `:ro`
   vale no device: o root do guest não o desfaz. A API recusa volume.
8. `runner.code`: `net`, `net_backend = "virtio-net"` (o `tsi` é recusado), `ports`, `[network]` e `volumes`. No
   `[dev]`, `ports` e `volumes` substituem a lista de cima.
9. Runbook com os passos novos, executados pelo `task runbook`.

## Dev Notes

- Gateway no processo `rc vmm`, nas goroutines, enquanto a libkrun ocupa a thread do `krun_start_enter`.
- O frame no socketpair é 4 bytes BE + Ethernet, sem cabeçalho virtio-net (features 0).
- Sem TSI, nem para `net` sem política. Toda máquina com rede passa pelo gateway, para
  o piso valer sempre.
- Volumes:
  - relativo no `runner.code` é resolvido a partir da pasta do arquivo;
  - `~` é expandido.
